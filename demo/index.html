Harness de modernización .NET

Migra un monolito .NET ruta a ruta. Sin paradas.

Una pasarela mueve cada ruta por cuatro etapas y solo corta cuando las dos respuestas coinciden.

Mover tráfico Ver comparación
  • 0paradas
  • 1ruta cada vez
  • 4etapas por ruta

Por qué

  1. Un monolito que funciona

    Nadie quiere tocarlo y reescribirlo entero es un riesgo.

  2. Una ruta cada vez

    La pasarela mueve una familia de rutas; el resto sigue igual.

  3. Pruebas con tráfico real

    Las dos respuestas se comparan antes de cortar. Vuelta atrás en un clic.

      04

      Cómo es una migración

      1. Aislar

        Elige una ruta y constrúyela en .NET 10.

      2. Ejecutar en sombra

        Envía la misma petición a ambos sistemas.

      3. Comparar

        Comprueba que las dos respuestas coinciden.

      4. Cortar

        Apunta la pasarela a la nueva API.

      05

      Qué incluye el repositorio

      • Pasarela YARP

      • Panel de control

        Tablero de migración, auditorías y tráfico en vivo.

      06

      Incorpóralo a tu flujo

      Rellena tus datos y copia el bloque. Nada sale de tu navegador.

      Sección Modernizer de src/NainLegacyModernizer.Gateway/appsettings.json

      Puesta en marcha

      1. Clona el repositorio y pega el bloque en appsettings.json.
      2. Arranca la pasarela y apunta tus clientes a ella.
      3. Abre /_modernizer y envía tráfico de prueba.
      4. Cuando el tablero diga Lista, promociona la ruta.
      git clone https://github.com/Nain9Dev/NainLegacyModernizer
dotnet run --project src/NainLegacyModernizer.Gateway

      Límites

      • Solo HTTP con JSON. No toca tu código ni tu base de datos.
      • El informe de paridad solo envía GET; sin cabeceras de autenticación aún.
      • Auditorías en memoria: un reinicio vuelve a la configuración.
      • El panel no tiene login: despliégalo dentro de tu red.
